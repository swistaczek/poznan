# jezyce/ — inicjatywa obywatelska (Jeżyce, Poznań)

Sprawa pierwsza: bezkolizyjne przejście pieszo-rowerowe przez linię kolejową 351 (rejon ul. św. Wawrzyńca / Poleska), łącznik Jeżyce ↔ Sołacz.

## Kontekst

Przejście przewidziane w MPZP „Jeżyce-Północ" (uchwały A1 XCVI/1851/VIII/2024, A2 VIII/110/IX/2024). Grunt zarządzany przez PKP PLK S.A. (linia 351 / E59) — nie miejski. Projekt PBO zgłaszany jako **manifest** (presja na realizację), świadom ryzyka odrzucenia formalnego.

Materiał referencyjny: [`../research/planowanie-przestrzenne/jezyce/index.md`](../research/planowanie-przestrzenne/jezyce/index.md).

## Struktura

```
rowery/
  index.md                      indeks obszaru (PUBLICZNY)
  pbo/projekt-pbo-*.md          projekt PBO, wersja zsanityzowana (PUBLICZNY)
  pbo/REJESTR.md                rejestr działań PBO (zsanityzowany)
  pisma/REJESTR.md              rejestr pism (zsanityzowany)
  pisma/YYYY-MM-DD_temat/        katalog sprawy (LOKALNY, gitignored)
  odpowiedzi/                   odpowiedzi urzędów/PKP (LOKALNE)
index.md                        indeks inicjatywy (PUBLICZNY)
```

## Dane osobowe

Wypełnione pisma i projekt z danymi nadawcy → wyłącznie lokalne foldery `pisma/YYYY-MM-DD_*/` (wzorzec `**/pisma/2*/` w root `.gitignore`). W repo tylko wersje zsanityzowane. Pełna reguła: root [`CLAUDE.md`](../CLAUDE.md).

## Adresaci pre-audytu

- **WGN UMP** (Wydział Gospodarki Nieruchomościami) — własność działek nasypu.
- **ZDM + PIM** — tunel w WPF / planach inwestycyjnych.
- **PKP PLK Zakład Poznań** — prędkość linii, status dokumentacji, warunki zgody (mapa zakładów: mapa.plk-sa.pl).

## Styl pism

Pełny protokół urzędowy (jak `szablony/`). Podstawa prawna konkretnie; sygnatury uchwał tylko zweryfikowane; klauzula formy doręczenia (e-mail/ePUAP/poczta).
